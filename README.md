# E-Commerce-Sales-Analysis-PowerBI
Interactive Power BI dashboard for analyzing e-commerce sales, customer behavior, product performance, and business insights.

## 📌 Project Overview

This project analyzes e-commerce business data using **Microsoft Power BI** to generate meaningful insights into sales performance, customers, products, categories, and business trends.

The project focuses on transforming raw business data into an **interactive dashboard** that helps understand business performance and supports data-driven decision-making.

The analysis covers different dimensions of e-commerce data and uses data cleaning, transformation, modeling, DAX calculations, and interactive visualizations.

---

## 🎯 Objectives

- Analyze overall e-commerce sales performance.
- Understand sales and revenue trends over time.
- Identify top-performing products and categories.
- Analyze customer purchasing behavior.
- Compare sales performance across different business dimensions.
- Identify high-performing and low-performing areas.
- Create meaningful KPIs for business performance.
- Build an interactive and user-friendly Power BI dashboard.
- Generate actionable business insights from the data.
